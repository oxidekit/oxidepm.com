Adapters

The core supervises processes. Features that are not part of that job are adapters you choose to install. Each adapter is a separate program, and you approve what it asks for before it runs.

$ oxidepm adapter search watch
$ oxidepm adapter info watch
$ oxidepm adapter import watch --enable

On Linux, import by name from the signed online catalogue. OxidePM 0.4.0 also bundles all 13 adapters for offline use. For example, run oxidepm adapter import --bundled watch --enable. The installer enables only the four runtimes for Node.js, Python, Go and Rust.

Review each additional adapter’s permissions and confirm the grant at the prompt. If approval is deferred, use the fingerprint printed by the import. For an adapter you build yourself, import the archive by SHA-256.

14 adapters

  • Service

    notifier

    Sends a message to Telegram, Discord, Slack or a signed webhook when an app starts, stops, restarts, crashes, loops, goes over its memory limit or fails a health check. Adds the notify command.

    Asks for permission to

    • Read app status and lifecycle events (read access only)
    • Make outbound network connections; the manifest names api.telegram.org, discord.com and hooks.slack.com
    • Write only to its own state directory
    • Receive OXIDEPM_TELEGRAM_TOKEN from the daemon's environment

    oxidepm adapter import notifier --enable

  • Service

    exporter-prometheus

    Serves /metrics in the Prometheus text format on 127.0.0.1:9616. On each scrape it asks the daemon for the status of the apps, and answers 503 with oxidepm_up 0 when it cannot.

    Asks for permission to

    • Read app status (read access only)
    • Make outbound network connections (no hosts named)
    • Listen on 127.0.0.1:9616
    • Read its own state directory, write nothing

    oxidepm adapter import exporter-prometheus --enable

  • Service

    ui-web

    Serves a REST API and a WebSocket on 127.0.0.1:9615 by default. Shows apps and can stop and restart opted-in apps. API requests require an access key except for /api/health. Adds the web command.

    Asks for permission to

    • Control the apps that list it (lifecycle access, opted-in apps only)
    • Receive lifecycle events
    • Make outbound network connections (no hosts named)
    • Listen on 127.0.0.1:9615
    • Read and write only its own state directory

    oxidepm adapter import ui-web --enable

  • Tool

    ui-tui

    The terminal dashboard: the apps with state, CPU and memory, the selected app in detail and its log. Stopping or restarting an app asks for y or n first. Runs only while the dashboard is open. Adds the monit command.

    Asks for permission to

    • Stop and restart apps (lifecycle access, all apps)
    • No network connections
    • No file access of its own

    oxidepm adapter import ui-tui --enable

  • Runtime

    runtime-node

    Runs Node.js apps: the node, npm, pnpm and yarn runtimes. It tells the daemon what to run and the daemon runs it.

    Asks for permission to

    • Read app status (read access only)
    • No network connections
    • Read only its own state directory, write nothing
    • Start no programs of its own: it tells the daemon what to run

    oxidepm adapter import runtime-node --enable

  • Runtime

    runtime-python

    Runs Python apps, in the project's virtualenv when it has one. Provides the python runtime.

    Asks for permission to

    • Read app status (read access only)
    • No network connections
    • Read only its own state directory, write nothing
    • Start no programs of its own: it tells the daemon what to run

    oxidepm adapter import runtime-python --enable

  • Runtime

    runtime-go

    Runs Go apps with go run. Provides the go runtime.

    Asks for permission to

    • Read app status (read access only)
    • No network connections
    • Read only its own state directory, write nothing
    • Start no programs of its own: it tells the daemon what to run

    oxidepm adapter import runtime-go --enable

  • Runtime

    runtime-rust

    Builds and runs Rust apps: a single file with rustc, a project with cargo. Provides the rust and cargo runtimes.

    Asks for permission to

    • Read app status (read access only)
    • No network connections
    • Read only its own state directory, write nothing
    • Start no programs of its own: it tells the daemon what to run

    oxidepm adapter import runtime-rust --enable

  • Tool

    check

    Check project readiness with oxidepm check. Use start --check to opt in to preflight for a single target.

    Permissions

    • Read files and app status
    • Write within the current working directory and its own state directory
    • Make outbound network connections and start programs

    oxidepm adapter import check --enable

  • Tool

    init

    Scan a project and generate oxidepm.config.toml with oxidepm init.

    Permissions

    • Read app status
    • Read and write within the current working directory and its own state directory
    • Require enforcement of its network block
    • Start no programs

    oxidepm adapter import init --enable

  • Tool

    git-start

    Clone or update a Git checkout and start it with oxidepm git-start.

    Permissions

    • Read files and app status
    • Write only inside its own state directory
    • Make outbound network connections and start programs
    • Receive HOME and SSH_AUTH_SOCK from the daemon environment

    oxidepm adapter import git-start --enable

  • Tool

    deploy

    Pull code and restart services with oxidepm deploy. Inspect the remote checkout with oxidepm diff.

    Permissions

    • Read files and app status
    • Make outbound network connections and start ssh
    • Receive HOME and SSH_AUTH_SOCK and request access to the SSH agent socket
    • Write no local files

    oxidepm adapter import deploy --enable

  • Service

    watch

    Restart opted-in apps when files change under the paths set in apps.adapters.watch.

    Permissions

    • Control opted-in apps and receive lifecycle events
    • Read files without writing
    • Require enforcement of its network block
    • Start no programs

    oxidepm adapter import watch --enable

Write your own

Any language that can read and write JSON

An adapter is a program that speaks the adapter protocol over its standard input and output. The protocol is documented and versioned. A manifest.json declares what the adapter asks for, and the person who enables it sees that list first.

If your adapter crashes or stops answering, the daemon restarts it with a growing delay. The apps the daemon supervises are not touched.
