Adapters

The core supervises processes. Features that are not part of that job are adapters you choose to install. Each adapter is a separate program, and you approve what it asks for before it runs.

$ oxidepm adapter import <archive> --sha256 <hex>
$ oxidepm adapter enable <name>
$ oxidepm adapter list
Not in the latest release (0.3.2)

The install command installs 0.3.2, the latest published release. The agent socket, audit log, dry runs, policy markers and adapters described on this site are not in that release, and the code that has them is not published yet. These pages describe what is coming. What 0.3.2 has and does not have.

Two adapters are built and tested: the notifier and the Prometheus exporter. Neither is published yet: there is no archive to download and no signed index. The index that oxidepm adapter import <name> and adapter search read does not exist yet either, so once an archive is published you import it and pin it with its SHA-256. How importing works.

14 adapters

  • Service

    notifier

    Sends a message to Telegram, Discord, Slack or a signed webhook when an app starts, stops, restarts, crashes, loops, goes over its memory limit or fails a health check. Adds the notify command.

    Asks for permission to

    • Read app status and lifecycle events (read access only)
    • Make outbound network connections; the manifest names api.telegram.org, discord.com and hooks.slack.com
    • Write only to its own state directory
    • Receive OXIDEPM_TELEGRAM_TOKEN from the daemon's environment

    Built and tested, not published yet: there is no archive to download and no signed index. Once there is one, import it from an archive pinned by its SHA-256.

  • Service

    exporter-prometheus

    Serves /metrics in the Prometheus text format on 127.0.0.1:9616. On each scrape it asks the daemon for the status of the apps, and answers 503 with oxidepm_up 0 when it cannot.

    Asks for permission to

    • Read app status (read access only)
    • Make outbound network connections (no hosts named)
    • Listen on 127.0.0.1:9616
    • Read its own state directory, write nothing

    Built and tested, not published yet: there is no archive to download and no signed index. Once there is one, import it from an archive pinned by its SHA-256.

Write your own

Any language that can read and write JSON

An adapter is a program that speaks the adapter protocol over its standard input and output. The protocol is documented and versioned. A manifest.json declares what the adapter asks for, and the person who enables it sees that list first.

If your adapter crashes or stops answering, the daemon restarts it with a growing delay. The apps the daemon supervises are not touched.
